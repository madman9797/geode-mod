# Flappy Maker Bird v1.0.0

A Geometry Dash Geode mod that adds a **BIRD?** button to the main menu and opens a Flappy Bird-style minigame using the player's icon as the bird.

## Android-ready

This repository includes `.github/workflows/build-android.yml`, which builds Android64 and Android32 `.geode` packages using the official Geode build action.

See `README_ANDROID.md` for phone-only build/install instructions.

## Gameplay

- BIRD? button on the Geometry Dash main menu
- Current player icon used as the bird
- Tap/click/space to flap
- Gravity and flap physics
- Block-built moving pipes
- Pipe collision and death
- Score counter
- Restart after death
- Back button to return to Geometry Dash

## Target

- Geometry Dash: 2.2081
- Geode SDK: 5.8.2
- Android targets: Android64 and Android32
